# 币安 / 欧易 内部转账收款

从 v1.26.0 起，BEpusdt 支持把 **币安（Binance）** 与 **欧易（OKX）** 的交易所账户作为收款通道：付款人在交易所 App 内向你的账户 UID 做内部转账（免手续费、秒到），BEpusdt 通过交易所的**只读 API** 轮询入账并自动认单、回调。

> 交易所内部转账不经过区块链，链上扫块看不到。这套能力借鉴了 [HashPay](https://github.com/TGDash/HashPay)（Apache-2.0）的做法。

## 原理

| 交易所 | 读取的记录 | 识别方式 |
|---|---|---|
| Binance | `Binance Pay` 交易记录（Pay ID / 邮箱 / 手机转账）+ 充值记录中的内部划转（其他币安用户提现到你的充值地址时由币安内部划转，`transferType=1`） | 收款方 Binance ID = 钱包 UID，币种 USDT / USDC |
| OKX | 资金账户流水（类型 1 充值、72 收到转账） | 流水 `balChg > 0`，币种 USDT / USDC |

入账进入与链上转账相同的管线：写入 `bep_chain_transfer` 流水 → 按「UID + 币种 + 金额 + 订单时间窗」匹配订单 → 交易所入账即终态，直接标记成功 → 回调 outbox。重复拉取、重启后重放都不会产生重复回调。

## 配置步骤

### 1. 创建只读 API Key

- **币安**：[API 管理](https://www.binance.com/my/settings/api-management) → 创建 API → 只勾选 **允许读取**，不要开启交易 / 提现；建议限制访问 IP 为 BEpusdt 服务器 IP。
- **欧易**：[API 管理](https://www.okx.com/account/my-api) → 创建 V5 API Key → 权限只选 **读取**，记下 Passphrase；建议绑定 IP。

### 2. 获取账户 UID

- 币安：个人中心 → 「Binance ID」（也是 Binance Pay 的 Pay ID），纯数字。
- 欧易：个人资料 → 「UID」，纯数字。

### 3. 后台添加钱包

`钱包管理` → `新增钱包`：

| 字段 | 填写 |
|---|---|
| 交易类型 | `USDT・Binance` / `USDC・Binance` / `USDT・OKX` / `USDC・OKX` |
| 账户 UID | 上一步的纯数字 UID |
| API Key / API Secret | 只读 API 凭证 |
| Passphrase | 仅 OKX |

点击「校验凭证与 UID」或直接保存：BEpusdt 会调用交易所账户接口，确认凭证可用且所属账户 UID 与填写一致，不一致会拒绝保存。凭证以 AES-GCM 加密后存入数据库，不会随接口返回。

一个 UID 同时收 USDT 与 USDC 需要分别添加两个钱包（可填同一套凭证）。

### 4. API 地址（可选）

`系统管理` → `区块节点`：`Binance API` 默认 `https://api.binance.com, https://api-gcp.binance.com, https://api1.binance.com`，`OKX API` 默认 `https://www.okx.com`。多个地址逗号分隔，遇到网络错误 / 限流 / 5xx 自动切换。

## 收银台

选择交易所网络后，支付页不再显示地址二维码，而是显示 **收款账户 UID** 与操作指引（币安：资金 → 提现 → 币安用户 / 内部转账，或 Binance Pay；欧易：资产 → 提币 → 内部转账），金额必须与页面完全一致。两套内置主题均已适配。

## 轮询与额度

- 只有存在待支付（或回溯窗口内）的交易所订单，或该钱包开启了「其它通知」时才请求交易所 API，空闲不消耗额度。
- 有需求时每 10 秒轮询一次，每次回看上次成功轮询前 10 分钟；首次启用回看 2 小时，长时间停机最多回看 24 小时。
- 币安 Pay 记录接口权重 3000 / UID / 分钟窗口，10 秒一次约 18000 / 分钟，远低于 180000 的上限；欧易流水接口限制 6 次 / 秒。
- 凭证失效（401 / 403 / 无效签名 / IP 不在白名单）会通过通知渠道告警（每钱包每小时 1 条），并停止对该钱包计成功。

## 补扫

交易所网络的「区块高度」是时间戳（unix 秒）。补扫某段时间的入账：

```bash
bepusdt scan replay --network binance --from 1789700000 --to 1789703600
```

或后台 `POST /api/scan/replay`，`from` / `to` 为 unix 秒，单次最多 5000 秒。补扫忽略去重缓存，流水表与订单匹配天然幂等。

## 风险与限制

- 个人账户用于经营性收款可能违反交易所服务条款，大量小额陌生入账可能触发风控冻结，请自行评估；规模较大时币安官方的 Binance Pay 商户接入是更合规的路径。
- 内部转账没有备注字段，只能靠「唯一金额 + 时间窗」匹配，与链上收款一致：同一 UID 同时段的待支付订单金额会自动错开。
- 只支持 USDT / USDC。
- 币安 Pay 记录与充值记录来自两套接口，理论上同一笔款项不会同时出现在两处；即便出现，第二条只会产生一次「非订单入账」通知，不会重复认单。
